# Joueur ≠ Personnage

### Petit rappel important

Un personnage peut :
- mentir ;
- avoir des préjugés ;
- faire des erreurs ;
- être colérique ;
- prendre de mauvaises décisions.

Cela ne signifie pas que **le joueur**, pense ou souhaite réellement ces choses.
De la même façon :
- Une critique adressée à un personnage n'est pas une critique du joueur.
- Une dispute entre personnages n'est pas une dispute entre joueurs.
- Un échec en jeu n'est pas un échec personnel.
- Nous sommes tous là pour raconter une histoire ensemble et passer un bon moment.

Cela dit certaines situations entre personnage peuvent mettre mal à l'aise les joueurs et rendre l'expérience moins agréable pour certains.

1. Vous avez déjà croisé Zybilna
Lors de votre enfance, une femme aux longs cheveux blancs est apparue à un moment crucial de votre vie :
- elle vous a retrouvé après que vous vous soyez perdu ;
- elle vous a guéri d'une maladie ;
- elle vous a sauvé d'un accident ;
- elle vous a offert un cadeau dont vous vous souvenez encore.
Madryck a reconnu votre nom dans les récits de Zybilna.

2. Vous avez survécu à l'impossible
Vous êtes censé être mort.
Un incendie. Un naufrage. Une bataille. Une terrible maladie.
Pourtant vous avez survécu alors que personne ne pensait cela possible.
Madryck pense qu'une puissance féérique veille sur vous depuis longtemps.

3. Vous êtes un rêveur
Depuis des mois, vous faites le même rêve :
Une route de pierres blanches. Des lucioles dans la brume.
Une femme dans un immense palais d'argent.
À votre réveil, le souvenir disparaît presque entièrement.
Madryck a appris que d'autres personnes faisaient exactement le même rêve.

4. Vous possédez un objet étrange
Un objet que vous avez trouvé ou hérité :
- une clé sans serrure ;
- une pièce ancienne ;
- un médaillon féérique ;
- une plume argentée ;
- une fleur qui ne fane jamais.
Madryck croit que l'objet est lié à Prismeer.

5. Votre nom apparaît dans une prophétie
Madryck a découvert un vieux texte.
Parmi des mots effacés figure votre nom.
Ou un détail qui ne peut correspondre qu'à vous.
Il ignore ce que cela signifie.

6. Vous avez déjà franchi un passage féérique
Par accident.
Enfant, vous avez disparu pendant quelques heures.
Ou quelques jours.
Peut-être même plusieurs semaines.
Quand vous êtes revenu, vous n'aviez aucun souvenir de ce qui s'était passé.
Madryck pense que le Feywild vous connaît déjà.

7. Quelqu'un vous a recommandé
Un ancien aventurier.
Un professeur.
Un membre de votre famille.
Avant de mourir, cette personne a confié votre nom à Madryck avec ces mots :
> « Si le jour vient où Zybilna aura besoin d'aide, c'est cette personne qu'il faudra appeler. »
